# Translation and extraction notes / 翻译与抽取说明

- **Source:** Zotero attachment HCGKFGPR, an open arXiv preprint (arXiv:2509.04291), not the publisher-formatted Chemical Reviews version.
- **Text extraction / 文本抽取：** selectable text layer; two-column pages were ordered left column then right column.
- **Coverage / 覆盖：** all extractable front matter, main text, table/figure captions and acknowledgements before the bibliography (pp. 1-36) are represented. The bibliography (pp. 37-46) is retained as bibliographic information only and is not individually translated.
- **Figures and tables / 图表：** 24 embedded-figure crops and 2 vector-table crops were saved in `assets/`; captions are bilingual and placed near an extracted substantive mention.
- **Formulae/OCR / 公式与 OCR：** no OCR was used. Mathematical symbols are preserved as supplied by the PDF text layer; a few ligatures/dash glyphs may follow the source extraction.
- **Uncertainty / 不确定性：** none of the prose blocks was intentionally skipped; figure placement falls back to the nearest preceding body block where no explicit first mention was recoverable.
