# Translation and extraction notes / 翻译与抽取说明

- **Source / 来源：** Zotero attachment HU94EF6Z, publisher PDF with a selectable text layer.
- **Text extraction / 文本抽取：** no OCR was used. Two-column pages were ordered left column then right column; hyphenated line breaks were joined conservatively.
- **Coverage / 覆盖：** all extractable abstract, main text, method/author-information blocks, figure/table captions, and the conclusion through p.10 are represented. The reference list (pp.11-12) is kept as bibliographic information only and is not translated item by item.
- **Figures and tables / 图表：** six embedded figure crops and one tightly clipped vector Table 1 crop are in `assets/`; every visual has an English and Chinese caption card placed near its first substantive mention.
- **Formulae / 公式：** formula symbols, units, atom labels and reaction-coordinate notation follow the selectable PDF text layer. No formula image OCR was required.
- **Uncertainty / 不确定性：** figure placement falls back to the closest preceding body block when the first mention is part of a layout-separated caption; no extractable prose block was intentionally omitted.
