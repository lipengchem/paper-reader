# Translation and extraction notes / 翻译与抽取说明

- **Source type / 来源类型:** Selectable-text, six-page PDF; no OCR was used. / 可选择文本的 6 页 PDF；未使用 OCR。
- **Coverage / 覆盖范围:** All extractable abstract, body text, section headings, method text, author information and acknowledgments are represented as Original-Chinese pairs. The bibliography is retained as a bibliographic record rather than translated entry by entry. / 所有可抽取的摘要、正文、章节标题、方法、作者信息和致谢均保留原文—中文配对；参考文献仅作为书目信息保留。
- **Layout / 版式:** The source is two-column. Blocks were recovered in left-then-right reading order within each page. / 原文为双栏，按每页先左后右的阅读顺序恢复。
- **Figures / 图表:** Seven numbered figure regions were tightly rendered to `assets/`; Fig. 2 is vector artwork and was cropped from the source page rather than extracted as a bitmap. / 7 个编号图区域均已裁剪至 `assets/`；图 2 为矢量绘图，采用页面区域裁剪而非位图直接提取。
- **Formulae and symbols / 公式与符号:** Mathematical notation, ion labels, units, model names, and citation markers are preserved from the selectable text. Minor font-ligature normalization may occur. / 公式符号、离子标记、单位、模型名称和引文标记按可抽取文本保留；可能存在轻微的字体连字归一化。
