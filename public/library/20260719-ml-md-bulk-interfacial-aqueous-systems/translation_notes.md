# Translation and extraction notes / 翻译与抽取说明

- **Source type / 来源类型:** Selectable-text, 31-page PDF; no OCR was used.
- **Reading coverage / 覆盖范围:** All extractable abstract, prose blocks, author information and acknowledgments are represented as English-Chinese pairs. The reference list is retained as a bibliographic record rather than translated entry by entry.
- **Layout / 版式:** The source is two-column. Text was recovered in left-then-right reading order and a small number of unambiguous column continuations were joined.
- **Figures / 图表:** Fourteen embedded numbered figures were extracted from the PDF to `assets/`. They are placed beside the first substantive block on or after their figure page; the page/block anchor makes any placement approximation explicit.
- **Formulas and symbols / 公式与符号:** Formulae, chemical species, model names and citation markers are retained as printed. OCR uncertainty is not applicable; any PDF font glyph normalization is limited to the minus sign.
